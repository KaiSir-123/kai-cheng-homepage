# Kai Cheng Research Homepage

Personal academic research homepage for Kai Cheng / 程凯.

The website presents research in Control Science and Engineering, Mobile Robot Localization, Multisensor Fusion, Factor Graph Optimization, SLAM, LiDAR, IMU, Stereo Camera and intelligent robotic systems.

## Tech Stack

- Next.js App Router
- React
- Tailwind CSS
- Three.js
- Static export for Netlify deployment

## Pages

- `/` - Homepage
- `/about/` - About Kai Cheng
- `/publications/` - Academic publications
- `/research/` - Research projects
- `/activities/` - Academic and professional activities
- `/blog/` - Research blog and technical notes
- `/blog/[slug]/` - Individual article pages

## SEO

The site includes:

- Page metadata
- Open Graph metadata
- Person, ScholarlyArticle, ResearchProject, Event and Article JSON-LD
- `robots.txt`
- `sitemap.xml`
- `manifest.webmanifest`
- Site icons

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The static output is generated in `out/`.
